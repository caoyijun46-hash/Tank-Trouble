# 坦克动荡 (Tank Trouble)

Unity 随机迷宫坦克对战原型：单机 AI / 本地双人 / 局域网 1v1（主机权威联机）。

## 玩法

- 每局随机生成迷宫（格数、seed、补开洞比例可配），坦克在迷宫中互射
- 常规武器为直射炮弹；场上定时刷新道具（间隔/上限/池可配），拾取获得**激光**或**追踪导弹**
- 击杀演出：慢动作 + 爆炸特效 + 镜头特写，数秒后新一局（迷宫重新生成）
- 三种模式：`VsAI`（对战电脑）、`Double`（同屏双人）、`Online`（局域网 1v1）

## 操作

| 玩家 | 移动 | 开火 |
|---|---|---|
| P1（主机 / 本地双人） | `W A S D` | `空格` |
| P2（客户端 / 本地双人） | `方向键` | `小键盘 0` |

## 联机架构（核心）

- **主机权威**：host 模拟全部世界状态；client 是"快照播放器"——没有任何玩法逻辑，只有插值缓冲
- **实体注册表**：场景中所有实体（坦克 / 子弹 / 道具等）统一注册，host 每网络帧（约 33Hz）全量广播姿态，client 端以壳 prefab 实例呈现
- **插值渲染**：client 永远渲染主机已确认的过去状态（固有延迟 ≈ 缓冲深度 × 快照间隔）；yaw 为周期量，插值走 `LerpAngle`
- **可靠性按数据类型选**：状态流走不可靠管道（丢帧由下一条全量快照纠正）；一次性事实（Spawn / Despawn / 回合结束 / 暂停 / 会话结束）走可靠管道
- **局域网发现**：UDP 广播公告（端口 7781）+ 单播加入请求（端口 7782），支持房间列表、等待房主开始、中途加入
- 无绝对时钟同步：插值进度按快照窗口的时间跨度与本地真实时间推进

传输层为 Unity Transport (UTP)。联机开发的完整上下文与踩坑清单见《联机开发交接.md》。

## 技术栈

- Unity **6000.5.8f1** + URP
- Unity Transport (UTP)：不可靠 / 可靠有序双管道
- Input System（InputAction，绑定序列化在 prefab 上）
- 数值参数全部收进 `Assets/Config/` 的 ScriptableObject（Unit / Ai / Round / Maze / Camera / Ballistic / Net 各一份）

## 项目结构

```
Assets/Scripts/
├── Map/       迷宫生成（决策/执行分层）与 A* 寻路
├── Combat/    弹道与弹药：子弹 / 激光 / 追踪导弹
├── Unit/      坦克（玩家 / AI）与道具

```

## 运行

1. 用 **Unity 6000.5.8f1** 打开项目
2. 场景：`Menu`（入口）/ `Main`（对局）/ `Client`（联机客户端，由菜单进入）
3. 单机：Menu 选 VsAI 或 Double；直接 Play `Main` 场景则按 `GameConfig.Mode` 的默认值进入联机 host（联机调试入口）
4. 本机双端测试：ParrelSync 开双 Editor（clone 作 client），回环 127.0.0.1

## 构建

`File → Build Profiles`（Unity 6）。要点：

- **Scene List 必须包含 Menu / Main / Client 三场景**，Menu 置于第 0 位作为启动场景——编辑器内加载场景不受列表限制，打包后的播放器只认列表，漏加会在运行时静默失败并报错
- 产物是整个文件夹（exe + Data + DLL），拷贝分发时缺一不可
- 首次运行的机器需放行防火墙 UDP 入站：7783（游戏）/ 7781（发现广播）/ 7782（加入请求）
